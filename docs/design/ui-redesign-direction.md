# 足球新闻 PWA 视觉方向

状态：已确认的主视觉方向（V1）

参考图：[football-news-ui-direction-v1.png](./assets/football-news-ui-direction-v1.png)

## 一句话定义

一个明亮、有现场感的专业足球新闻出版物：用国际新闻产品的编辑秩序承载足球内容，用高质量图片、克制的品牌色和非对称排版建立高级感。

高级感来自图片选择、信息层级、比例、留白和排版，不来自深色背景、金色、毛玻璃、渐变或装饰堆叠。

## 产品结构

- 顶层只保留 `最新消息` 和 `近期热点` 两个频道。
- 移除 `世界杯` 标签页。
- 移除日期、足球图标和票根式飞出动效组成的旧头部。
- `最新消息` 保留双列瀑布流，服务高频刷新和快速浏览。
- `近期热点` 保留“一篇主新闻 + 两篇次新闻 + 后续列表”的编辑结构。
- 两个页面使用同一套头部、色彩、字体、图像处理和元信息规则。

## 核心气质

- 明亮、现代、专业、有比赛现场的生命力。
- 像成熟新闻编辑部，不像比分工具、赛事运营页或体育社区。
- 信息密度可以较高，但视觉层级必须清楚，不能拥挤。
- 品牌表达集中在头部和少量关键状态，正文信息流保持克制。

## 视觉系统

### 色彩

| 用途 | 建议色值 | 规则 |
| --- | --- | --- |
| 页面底色 | `#FAFAF8` | 接近白色，避免纯灰和复古米黄 |
| 主文字 | `#171817` | 标题、品牌和关键导航 |
| 次文字 | `#7D817E` | 来源、时间和说明 |
| 品牌珊瑚红 | `#E33B2E` | 当前频道、更新状态和少量品牌识别 |
| 品牌浅色面 | `#FFF0EC` | 当前频道的轻背景 |
| 分隔线 | `#E8E9E6` | 只用于必要的结构分隔 |

珊瑚红只承担识别和状态，不大面积铺满信息流。页面不增加第二个强势主色。

### 字体

- 使用项目已有的 `Geist Variable`，中文回退为 `PingFang SC`、`Noto Sans SC` 和系统无衬线字体。
- 不使用传统报纸衬线字体，不使用倾斜、描边或电竞风标题字。
- 品牌字标可以稍紧凑、偏粗，但不能夸张到抢走新闻内容。
- 字间距保持 `0`，通过字号、字重和留白建立层级。

建议移动端字号：

| 内容 | 字号 | 字重 |
| --- | --- | --- |
| 品牌字标 | 20–22px | 750–850 |
| 顶部频道 | 17–18px | 当前 650，非当前 500 |
| 重点新闻标题 | 18–20px | 650–750 |
| 普通新闻标题 | 15–17px | 600–700 |
| 来源与时间 | 11–12px | 450–550 |

### 形状与层级

- 圆角控制在 `0–5px`。
- 不给每条新闻套独立卡片。
- 默认无阴影，以留白和细分隔线组织内容。
- 不使用大胶囊按钮、悬浮面板、毛玻璃或卡片套卡片。
- 图标使用 Lucide 或现有图标库，线宽和尺寸保持统一。

## 顶部导航

- 左侧为菜单，中间区域容纳紧凑品牌字标和两个频道，右侧为搜索。
- 头部高度必须克制，首屏尽快露出新闻图片。
- 当前频道使用浅珊瑚色背景与深珊瑚红文字。
- 禁止使用来回移动的底部横线表示当前频道。
- 头部下方可显示一条轻量更新信息，例如 `刚刚更新 12 条`。
- 品牌名称尚未定稿，参考图中的 `信号编辑部` 只代表字标位置和视觉重量。

## 最新消息

- 使用真正的非对称双列瀑布流，而不是等高卡片网格。
- 推荐交替使用 `4:5`、`3:2`、`16:10` 等图片比例，形成稳定但不机械的高低错落。
- 图片应明显大于旧版，优先展示比赛动作、场边、训练、发布会和球迷现场。
- 标题主要放在图片下方；最多只允许一条重点新闻使用很轻的图片底部渐隐标题。
- 标题根据内容自然显示 2–4 行，不应为了整齐强制截断。
- 来源与时间保持小而清楚，更新时间可以用珊瑚红强调。
- 建议页面左右边距 `16px`，列间距 `10–12px`，图片与标题间距 `8px`，新闻单元纵向间距 `22–28px`。

## 近期热点

- 延续已确认的“一主两次再列表”结构，不改回普通瀑布流。
- 主新闻以高质量大图形成首屏焦点，两个次新闻保持并列。
- 三篇头部新闻的标题可放在图片上，但只使用轻柔、透明的底部暗色渐隐层。
- 渐隐层必须让原图清晰可见，并随标题的实际行数自适应高度。
- 标题不限制为两行，不做省略号截断。
- 后续列表使用清楚的图片、标题、来源和时间层级，不堆叠标签。
- 此频道不区分已读和未读，不允许因为已读而整体变灰或降低图片饱和度。

## 图片规则

- 图片承担主要情绪，必须优先保证清晰度、主体和裁切质量。
- 通过 `object-position` 针对不同图片调整主体位置，不能只依赖统一居中裁切。
- 避免海报图、文字过多的截图、模糊社交媒体截图和重复人物近景占满信息流。
- 不为营造“高级”统一降低饱和度、增加灰雾或给图片套暗色滤镜。
- 收藏按钮每条新闻只保留一个，放在统一位置并使用同一个状态源。

## 明确禁止

- 黑色或深灰大面积页面、悼念感和“人去世了”的沉重气质。
- 复古报纸米黄、咖啡色、奢华金和杂志古典衬线字。
- 电竞霓虹、蓝紫渐变、博彩盘口、比分工具化模块。
- 圆形球队入口、赛事数据、排行榜等与当前产品无关的功能堆叠。
- 大量卡片、阴影、圆角矩形、玻璃拟态和装饰线条。
- 当前频道横线动画。
- 为排版整齐而截断完整新闻标题。
- `近期热点` 的已读灰度状态。

## 验收标准

- 首屏一眼能识别品牌，但品牌不压过新闻内容。
- 两个频道切换时视觉稳定，当前状态清楚且没有横线错位。
- `最新消息` 在 390px 宽度下仍是自然错落的双列瀑布流。
- 长标题完整显示，图片、标题和元信息无重叠、无裁切。
- `近期热点` 的主次层级明显，并与 `最新消息` 属于同一套设计系统。
- 页面整体明亮、有活力、专业，不呈现沉重、复古或普通体育工具感。
- 设计在 PWA 手机视口中成立，桌面端大面积留白不是优先问题。
